# 蜘蛛跨版本连续翻译首轮结果

日期：2026-10-18。模型：配置的本地网关 `deepseek-flash`。输入使用先前冻结的 `pilot-v3` 独立版本索引，以及与其 fingerprint 一致的 `embedding-3-v1/corpus`。

后续已对原始响应、实体目录及实际 prompt 进行离线归因，详见 [问题归因与修复计划](translation-cross-edition-repair-plan.md)。其中区分了跨段重组、称谓形式混用、中文漏抽与局部召回缺口；计划中的运行时代码修复尚未实施。

本轮已完成连续接入及实测：五个 Web 条目生成了译文，其中四个完成覆盖映射、审校、裁决和 working 提交，第五个因段落合并及无效映射阻断。已验证四章前缀的增量索引、上下文压缩和恢复；**尚未达到五章窗口全部通过，更不能据此宣称高质量或全书可用。**

## 实现范围

- 复用 `SequenceEngine` 和 SQLite 不可变提交体系。新增 `translation/editions/sequence.py` 负责冻结独立版本材料并接入连续上下文；没有另建连续状态机。
- 初始历史来自 Web 独立 L2，邻近原文和外版参考各有来源。文库不挂到 Web 的平行译文槽位；连续生成的中文才与其实际 Web 原文绑定。
- 翻译、审校、裁决共享用途受限的跨版本材料。当前目标章有事件证据时取文库局部正文；没有关联时仍能依靠 Web 历史和可用术语继续。
- 新生成译文进入已有双语增量提取、候选知识、父目录和检查点流程。译法只记为 `provisional_rendering`，不因反复出现而变成人工确认译名。
- 增加段落数硬检查、参考材料与最终上下文共享预算、冻结投影、重复恢复校验和只读实测报告导出。

入口为 `scripts/run_cross_edition_sequence.py`；只读报告入口为 `scripts/report_cross_edition_sequence.py`。完整模型请求、响应、段落映射、审校、裁决和译文集中于 [实测材料目录](../artifacts/translation/spider-independent-index/continuous-v1/report.md)。

## 压缩与预算问题

首次计划第五章时，旧版参考注入重复了最近三章日文，并在每个外版段落携带 revision、原生 ID 等元数据。最终上下文超过本次80,000安全输入 tokens 的软上限，发送前被拦截。此时模型容量规划为131,072上下文、16,384最大输出、1.05估算膨胀系数及2,048安全余量；它是本次试验配置，不代表网关模型真实上限。

在四章已提交的同一前缀上建立检查点：

| 变化 | 安全输入估算 tokens |
| --- | ---: |
| 压缩前，四章完整生成历史 | 107,468 |
| 压缩后，最近三章完整双语＋较早范围的 L2 | 104,214 |
| 同一检查点，精简参考投影并去重完整 Web 历史 | 53,054 |

第一步确实移除了 `page10` 的完整正文，将其纳入可追溯的 L2；不是只给检查点更名。但联合抽取产生候选知识，新摘要也覆盖部分近章，因此净节省只有3,254 tokens。第二步大幅下降主要来自去重和精简字段，**不能将这部分计作摘要压缩收益**。最终发送的第五章 translation 请求由服务端报告50,245 prompt tokens。

新增投影保留段落引用、正文、版本和用途，原始完整包保持不变。已经完整提供的 `page11–13` 日文不再重复注入；四份文库局部参考与八条术语候选均保留，没有靠删除它们取得这次53k结果。若仍超预算，工程会按优先级删去可选摘录、其次术语，并记录 omissions。

审计材料分别见 [压缩前后完整上下文](../artifacts/translation/spider-independent-index/continuous-v1/compression-audit.json) 与 [相同快照下的参考投影比较](../artifacts/translation/spider-independent-index/continuous-v1/reference-projection-audit.json)。前四章使用原投影，第五章使用精简投影；本轮没有在同一目标上做语义质量 A/B，不能宣称精简提高了译文质量。

## 增量知识与恢复

最终四章前缀形成一个开放 L2 修订，并写出父目录元信息。保留的记录为：15个 ENTITY、12个 EVENT、9个 TEMPORAL、11个 PERSPECTIVE、7个 STATE、6个 NEED，以及 SUMMARY、COVERAGE 各1条。实体引用对应实际新译文，节点绑定四个提交及原文／译文依赖。

节点状态为 `partial`，有1个实体记录因 `name_not_in_evidence` 被隔离，仍保留原输出。COVERAGE 也报告提取未穷尽。原文与完整索引见 [已提交前缀索引](../artifacts/translation/spider-independent-index/continuous-v1/committed-prefix-index.json)。这不是完整实体表或已审事实库。

索引内容仍有模型缺陷：摘要开头称“三章”，随后实际概括了 `C0010–C0013` 四章；COVERAGE 声称未单列“天の声（仮）”，而实体记录实际包含它。节点结构的四章来源清单是程序事实，模型自然语言计数和完整性说明仍需谨慎使用。实体增量还会保留首稿的“冈酱／理保子”，因此 `provisional_rendering` 标签不能省去。

恢复测试还发现并修正了一个工程问题：SQLite 对象序列化调整 JSON 键顺序，使恢复时重新渲染出的投影字符串与原 prompt 字节不同。现在比较投影结构及引用选择，并保留原始已发消息，避免错误判定快照变化。旧版未精简的冻结上下文也保留兼容。

真实重复恢复前后均为4个提交、23次请求，head、checkpoint、workset、epoch不变；对四章前缀重复物化也没有新增请求。第五章草稿保持阻断。详见 [恢复审计](../artifacts/translation/spider-independent-index/continuous-v1/resume-audit.json)。

## 本次暴露的翻译与审校问题

1. **称谓候选的语用形式仍有问题。** `岡ちゃん` 的候选值是“冈崎香奈美”，但其中文用例本身含“外号冈姊”。首稿用了“冈酱”，审校未指出。这既涉及候选把爱称连接到实名，也涉及模型没有从用例选择合适的称呼形式。
2. **局部参考会遗漏有用译名。** 本轮 `リホ子` 没有专门的术语候选，首章所选文库正文只是裂缝结尾附近四段，未包含此前试点查到的“真贞子”用法。首稿用了“理保子／真实恐怖子”，审校也未指出。这里首先是材料选择不足，不能全部归因于审校模型能力。
3. **行文仍有生硬之处。** 例如 `無駄にテンションが上がってしまった` 译成“白白地情绪高涨”，第13项也有“但那种事就退缩的精神”等不自然表达。零 findings 没有反映这些问题。
4. **第五章违反逐段输出要求。** `J065–J067` 是条件描述、系统语音、回答叙述三个段落；首稿把其中一部分叙述提前合并，最终只有68行。这不等于发现了整段剧情漏译，但不满足本试验布局约束。
5. **映射重试没有修好无效 ID。** 三次响应都引用 `C0014.Z069`，实际译文到 `Z068` 为止。诊断 prompt 已指出错误，后两次仍重复同一映射。这些请求仅约4.2k／6.0k／7.8k输入 tokens，不能用长上下文注意力溃散解释全部失败。结构校验正确阻断，不能把请求正常返回当成流程成功。

已将段落数检查提前到映射／审校之前，修订稿也需经过该检查，提交前再次复核。恢复第五章现在直接返回明确的69／68错误，不再支付额外映射调用。原始三次失败映射保留在调用21–23中，便于继续研究。当前没有新增自动段落重排或重新翻译机制，尚未修复第五章草稿。

正向抽查中，第12项的毒牙 LV2→LV3、第13项称号授予与毒抗性统合，以及第五章草稿的技能等级列表基本保持 Web 字面信息；新译文能采用“蜘蛛丝／毒抗性／食亲者”等有中文用例的译法。但这些抽查不足以证明整体忠实度，也未完成叙事诡计、隐瞒身份、远距时序和版本污染的专门评价。

## 成本、验证与验收边界

共23次远程调用正常返回：翻译5次、映射7次、审校4次、裁决4次、增量提取3次。其中3次正常返回的映射在结构上失败，第五章未进行语义审校或裁决。

服务端累计用量为1,029,312 prompt tokens、36,295 completion tokens；报告的 prompt cache hit 为353,536 tokens，cache miss 为675,776 tokens。预算阻断和修复后的重复恢复没有新增远程请求。调用成本仍主要来自反复携带历史与证据，不能把消息可复用直接解释为稳定缓存命中。

全量回归490 passed，1条既有 `pkg_resources` 弃用警告；独立版本与连续桥接针对测试40 passed。新增测试覆盖：不伪造平行译文、连续五章 mock 流程、实际移除旧正文的压缩、恢复不重复请求、语料／参考包变化拒绝、段落合并提前阻断、可选参考共享预算、投影序列化后恢复，以及审校只注册实际选入的外版引用。

本轮具备继续试验的连续管线，四章实际提交、可追溯增量索引与一次真实上下文压缩均已完成。剩余的明确门槛是第五章布局恢复，以及称谓候选和定向材料召回；全书自动候选搜索、跨多个新 L2／L1 的长跑和语义质量基准仍不在本次已验证范围内。
