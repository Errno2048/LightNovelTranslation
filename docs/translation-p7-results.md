## 2. 回归与故障恢复

全量命令为 `python -m pytest -q tests/translation`：**373 passed，10 条既有第三方依赖警告**。`compileall` 与本轮改动的 `git diff --check` 通过；用户已有爬虫入口修改保持原样。

P7 专项验证了响应落盘后中断、提交事务内外中断、检查点保存后／切换前中断；恢复不重复请求、不重复提交，孤立产物不自动成为活动头。另验证抽取三次失败后保留全文、工具续接共享三次上限、正常结束后物化尾部，以及不整除／有缺口边界下的检查点触发。

最终代码的离线回放也已完成：已完成的 U 分支续译与尾部物化以 **0 次新模型调用**恢复，活动头与账本保持不变；H 检查点重新编译出的完整 context 与原保存内容完全一致。审计结果见 `offline-current-code-replay.json`。

`accepted_only` 另以 mock 验证：满足原 P5 条件时两个正式头可进入后章依赖；存在未决时阻断且接受记录为空，不静默降为 working。真实实验均未启用该模式。小窗口角色配置还验证了映射／修订／转录不再被新运行中隐含的旧输出上限阻断；最小上下文放不下时可导出带分消息占用的未发送诊断。

真实并发写产物暴露两个本地问题：固定 `.tmp` 文件会互相覆盖；Windows 并发 rename 偶发拒绝访问。写入改为同目录唯一临时文件、fsync、原子 replace，并只对 Windows 指定文件占用错误进行最多八次短退避；没有增加模型调用次数。

真实裁决另出现“已确认”枚举及 DECISION 多写 `source_ref/target_ref`。限定在 audit-v5 的恢复增加封闭枚举别名；额外定位必须确实存在且与原 finding 的段落相同。未知字段、假引文、错段和歧义 ID 仍阻断。1200/H 第 34 个、1200/R 第 12 个原响应均零调用恢复解析，两个账本请求数不变；确认意见仍须经过正常补丁和回归，不因修复格式自动提交。原失败及恢复记录均保留。

## 3. 试验范围与预算

产物根目录：`artifacts/translation/tenken-cache-clean/verification/p7-pilot-20261017/`。

冻结窗口起点为 main:610、main:701、main:1200，每窗 13 章；全窗参考中文从生成输入中剔除，未与保护集重叠。继承历史摘要本来有 6、0、91 章缺口，逐范围显式保留，没有宣称已总结全部前文。main:1200 的物理 source ID 为 `ja:syosetu:n6006cw:1202`；阅读章号与物理 ID 不混用。

模型仍为 glm-5.3-flash；1,048,576 总上下文、131,072 输出硬上限来自本项目配置。翻译请求预留 8192，审校／裁决／索引预留 16384，压缩预留 8192。本轮不调用 embedding。每分支冻结上限为 160 次、16M 安全输入预留、2.4M 输出预留，每逻辑任务最多三次。

这批旧冻结 spec 的映射／修订／转录沿用各 16384 的上限；新的 TOML 运行已支持辅助角色分别配置并继承相应主角色预算。请求虽设置 `thinking=false`，供应方仍返回部分非零 reasoning 用量，统计照实保留，不把开关当作零推理或零开销保证。

短窗口主动使用 **L1=9、L2=3** 的压力布局，便于观察闭合、抽取和父级更新；这不是正常 100/10 在 1M 硬窗口中自然越界的证据。长输出与小窗口模型能力也没有据此得到验证。

早期数个流程的三次网络失败来自环境代理 TLS reset。无认证同站诊断显示代理路径失败、直接连接返回 HTTP 200，随后改用 direct HTTP client，证书校验保持开启，记录在 `transport-revision.json`。已耗尽的任务没有重置，也没有通过换 ID 或新建等价分支逃避上限。未知远端用量保留预留，无法填补实际账单。该传输变更单独列示，因此本轮不是严格同环境的完整对照。

- 各窗口 `frozen.json/inputs.json/spec.json`：完整输入、模型、预算、隐藏范围及已有开发标注。

代码在真实冒烟期间有修正；已启动 Python 进程仍执行启动时版本。所有原请求、输出及冻结输入保留，早期 prompt 不能被后来补上的缺口注入或 seed 移出全文逻辑追溯替换。因此独立长运行的质量差异不能直接作严格因果比较，共同前缀试验单列。

## 7. 验收结论及后续

工程能力可用于有界、可恢复的连续实验；尚不能作为全书自动翻译并接受的质量方案。真实多窗口存在预算内网络阻断、格式变体与语义错误，完整 13 章 × 多窗口 × 三策略未完成。结构化抽取仍会隔离不支持的译名／事件；候选信息可能随生成中文的错误累积，需保持来源与可查证性。

离线节点规划使用显式协议／前驱余量；带历史导航的实际抽取消息另做完整预算检查。某些较小窗口仍可能因历史导航过大而阻断，当前没有自动重压抽取前情。fork 继承有效前缀文本、候选及原始提交身份，旧分支索引对象不自动变成本分支对象；需要旧索引细节时保留原数据库供追溯，当前分支工具也可直接查询继承正文。

后续优先补齐可控传输下的长窗口共同前缀对照、检查点前后原文审查及不同模型比较，分开判断抽取、翻译和审校能力。分卷边界、长期工作集筛选、正式评测和 EPUB 导出仍不在本轮已验收范围。
