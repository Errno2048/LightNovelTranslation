# P8 定向词条与局部证据对照实验

日期：2026-10-18。模型：当前配置的 `deepseek-flash`，temperature=0，thinking disabled。

**定向历史词条改善了 446 章的初译命名与审校定位；局部证据改善了 441 章的审校，但没有纠正初译的“新鲜”解释。单独缩短上下文也未解决该歧义。不能据此认为两章已经完整修复或 P8 已通过验收。**

## 实验范围与控制

- 人工指定两个已知错误探针：441 的 `フレッシュ・グレーター・ゴーレム`／`フレッシュ・ゴーレム`，446 的 `ホーリー・オーダー`。这不测自动专名检测的召回率，也不是新的盲测。
- 原 P8 已开放参考。本实验另建目录，模型输入不加入目标章的参考中文或未来章节；446 的历史中文证据来自第180章。
- 初译部分保留当时完整消息前缀及当前日文。A 组消息逐字复用；B、C 只在当前任务之前插入一个证据消息。
- 审校部分三组使用同一份 round-0 旧译稿。复用旧首审消息，B、C 只额外注入相同的证据包，避免“初稿不同”干扰检出率比较。
- 裁决、补丁在各组使用相同模板和历史上下文。审校采用现有 audit-v6 解析；补丁校验目标位置、段落 hash、已确认意见覆盖和段落数量。
- 这是独立实验脚本，未通过 SequenceEngine 提交，也没有完成规则 SIGNAL 的全流程处置或修订后的完整回归。结构可解析、引用可定位、补丁可应用均不等于语义正确。
- 两章相互独立，并发执行；每章内部 A→B→C 串行。主实验预留最多36请求，实际24请求；另做2请求的短上下文辅助诊断。

## 三组输入

| 组别 | 新增信息 |
|---|---|
| A | 无，实时重跑原有上下文 |
| B | 当前词形、全部出现段落及次数；有历史词条时提供既有译法与日中出处 |
| C | B，加命中段前后各2个非空日文段落，合并重叠窗口；明确要求核对名称与定义、材料、性质、行为是否相容 |

441 没有历史译法注入，仅列出 J017、J023 两个原文名称及位置。B、C 均未给出 Fresh/Flesh 这两个英文候选，也没有提供“肉身／肉体”的中文答案。

446 注入的信息为：

```text
名称：ホーリー・オーダー（兼容无中点写法）
观察到的历史译法：神圣秩序（Holy Order）
描述：圣灵剑，神剑之一；具体设定以引用日文为准。
日中用法证据：C0180.J069 / C0180.Z073
定义证据：C0361.J066
本章出现：C0446.J007 ×1；C0446.J008 ×2
状态：历史对照中的既有用法，未作为全书审定规则
```

完整资料包与增加的通用指令均保存在各组的 `evidence.json`。C 组同时改变了证据呈现和核对指令，因此其改善不能单独归因于“前后两段”这一因素。

## 446：定向词条改善初译，但旧稿修订仍不完整

| 组别 | 新初译 | 同一旧稿的审校定位 | 裁决与补丁结果 |
|---|---|---|---|
| A | 三处仍为“圣灵骑士团”；J007 仍为“那帮家伙” | 术语意见集中在 Z008，漏 Z007 | 只把 Z008 改成“霍利·奥德”，Z007 留旧译，复现原问题 |
| B | 三处统一“神圣秩序”；J007 为“那混蛋” | Z007、Z008 均检出，并实际引用 C0180.Z073 | 三处名字均改为历史译名，但 Z007 仍留下“那帮家伙” |
| C | 三处统一“神圣秩序”；J007 为“那混蛋” | 同样覆盖 Z007、Z008 | 名字全部统一，仍保留“那帮家伙”；相对B未见新增修复 |

B 初译的相关正文：

> 「一百年前吗，五百年前吗，一千年前吗。已经搞不清了，但被神圣秩序那混蛋差点破坏的事还隐约记得！」
>
> 神圣秩序？我记得！是阿莉丝缇娅教过的神剑之一！圣灵剑神圣秩序。据说是为对抗狂信剑法纳提克斯而造的神剑。

这说明历史名称与出现集合确实对本例有效：不仅恢复既有译法，也使旧稿审校枚举了两个受影响段落。但模型确认“这是剑”后，仍未要求把群体指代改为单体指代；裁决甚至在修复建议中重复了“那帮家伙”。引用正确不代表实体理解已经落实到完整补丁。

审校理由也有细节错误，例如 C 组把日文 C0361.J066 描述成提供了中文译法；实际支持中文名称的是 C0180.Z073。该问题没有破坏本次引用定位，却表明理由仍需要核对。

## 441：局部证据帮助审校，未解决初译消歧

| 组别 | 新初译 | 同一旧稿的审校／裁决 | 补丁结果 |
|---|---|---|---|
| A | “新鲜大石像鬼／新鲜石像鬼” | 仍把注意力放在“大／高等”等名称形式，没有识别核心问题 | “新鲜·高等石像鬼”，核心问题保留 |
| B | “新鲜·大·魔像／新鲜·魔像” | 仍未发现“新鲜”的词义疑点 | 旧稿改为“新鲜上级石像鬼”，仍保留错误理解 |
| C | “新鲜·大·魔像／新鲜魔像” | J017、J023 均报 major；用同段“死体を使ったゴーレム”解释为何需要重查名称，裁决确认 | 两段分别改为“弗雷什·大格雷姆”和“弗雷什·哥雷姆”，避开“新鲜／石像鬼” |

C 组审校首次明确指出：

> 后文说明其为用尸体做成的哥雷姆；草稿把「フレッシュ」按字面“新鲜”处理，且“石像鬼”通常对应别的魔物，名称含义与原文“尸体哥雷姆”的说明不相容。

其修复方向是避免武断直译、改用音译。它没有明确选择 Flesh／肉身的含义；“格雷姆／哥雷姆”还出现了同系列名称写法不统一。因此应记作**检出改善和保守修订**，不能记为完整的词义恢复。

后续核查修正：上述模型理由中的“不相容”过强，尸体也可能新鲜；这条理由不能独立证明 fresh 错误。441 同章 J044 的「肉兵」、后文的肉体材料定义及外部 Flesh Golem 领域名称提供了更完整的支持链。详见 [词义证据与主线接入说明](translation-p8-flesh-analysis.md)。

A、B 的一些审校意见本身也不成立：旧稿本来就用“大”区分了两个名称，裁决仍确认了“层级丢失／两处混同”等解释。C 的意见同样夹杂了不充分的一致性指控。不能以 finding 数量增加衡量语义质量。

## 辅助诊断：仅给短段落，再把模型术语卡送回翻译

主实验完成后，另做 D-local-probe，共2次调用：

1. 只给 C 组相同的词形、位置、日文窗口和一般消歧要求，不给当前中文草稿或英文候选；实际输入1037 tokens。
2. 将模型生成的候选术语卡连同 C 组资料包送回原有长上下文，重新初译一次；没有择优筛选术语卡。

模型在短上下文中正确认出对象是尸体傀儡，却建议“新鲜巨型魔像”，并解释为“新鲜／未腐”。原文没有明确说明尸体新鲜或未腐。随后长上下文初译沿用了这张卡的“新鲜巨型魔像／新鲜魔像”。

这次结果不支持“只要把局部段落单独摘出，模型就能完成消歧”。错误还涉及词义候选的生成和核验；同模型生成的候选卡也可能把错误解释进一步固定。该辅助诊断没有进行审校、裁决或验收。

## 开销与检查

- 总计26次真实调用：主实验24次，辅助诊断2次。
- 实际输入4,169,533 tokens，输出16,359 tokens；其中输入缓存命中4,074,752 tokens。未根据缓存命中推算金额。
- C 相对 A 的初译请求：441 输入193,001→193,932，增加931；446 输入213,304→214,190，增加886。新增证据包约占原输入的0.4%—0.5%。
- 六组审校、裁决均可解析，六组补丁通过位置/hash/范围检查并可零调用重放。
- 原始实验的冻结输入、生成封存文件、参考开放标记 hash 均未改变；数据库只读访问。
- 脚本编译检查与离线完整性检查通过。未据此宣称新译文通过完整审校，或推算其他章节的正确率。

## 后续采用范围

可以优先把“当前专名匹配 → 定向历史用法 → 本章全部位置”接到初译和审校，词条描述与出处保留质量标签；这次446的改善是直接证据。

局部窗口更适合作为审校重点证据，而不能保证初译自动采用正确解释。对未知片假名，后续可单独测试通用词典的多义候选或更强的消歧模型；本次尚未测试这两种方法。暂不把同模型短上下文生成的术语卡提升为硬约束。
