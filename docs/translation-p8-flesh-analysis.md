# P8：フレッシュ 的消歧证据与主线接入

日期：2026-10-18。

## 判断

**“尸体材料”不能在逻辑上排除 fresh；但本作的材料定义、同指称呼及奇幻领域的 Flesh Golem 名称共同强烈支持 flesh。现有证据足以优先译作“肉身／血肉魔像”，还不足以声称获得了作者英文拼写的直接确认。** 中文具体采用“肉身”“血肉”或既有约定，仍是另一层翻译选择。

上一轮 C 组审校把“新鲜”与“尸体”说成语义不相容，理由过强。尸体可以新鲜，肉身魔像也可以刚制成；需要比较哪种名称解释得到正文与领域惯例的正面支持，不能靠想象一种矛盾来确认错误。参考译文同样不是作者意图的独立证明。

## 441 章当时已经具备的证据

| 位置 | 原文要点 | 支持范围 |
| --- | --- | --- |
| `C0441.J017` | 「鑑定すると、フレッシュ・グレーター・ゴーレムと出る。どうやら死体を使ったゴーレムであるらしい。」 | 名称来自鉴定，紧接着按制作材料解释对象。支持“材料型魔像”的解释；未交代尸体新鲜、未腐等性质。 |
| `C0441.J023` | 「フレッシュ・ゴーレムを10体以上倒している」 | 这是可用于多个对象的种类称谓，不能凭这一句判断 fresh/flesh。 |
| `C0441.J044` | 「肉壁どもがちょうど敵の目を引き付けておる。…肉兵は無視して、まずは剣持ちを減らすぞ」 | 战术区分中的「肉兵」从叙事指称上支持先前的尸体魔像为“肉制士兵”。这里的「肉壁」与「肉兵」需区分，不把两者都强行指向魔像。 |

J017 的定义与 J044 的称呼都在原实验的完整日文输入中。它们并未因索引压缩而丢失。J044 距离名称的 J017/J023 较远，前后两段的局部窗口没有收录这一称呼。这暴露的是**名称、定义和无同词形的同指称呼没有被联系起来**，不只是上下文数量不足。

“鉴定名＋材料说明”也提示应把整个复合名称作为领域词语检索，而不是独立把最常见的音节解释拼起来。但鉴定名本身不是英文拼写证据，虚构作品仍可能使用特殊命名。

## 后文校验：仅供本次分析

| 位置 | 原文要点 | 意义 |

| `C0442.J041` | 「人の肉を使ったが故に、麻痺毒はフレッシュ・ゴーレムに対して有効か」 | 剧情效果由“使用人肉”解释，不是由“新鲜”解释。 |

| 番外「閑章二 海中ダンジョン 12」`CX14F4378F9B78.J054` | 「千切れた肉体を一時的にフレッシュゴーレム化して操る」 | 同样以肉体被操纵为魔像来说明机制。 |

这些是确认译法时有用的作品内部交叉证据，但**不得作为 441 章顺序翻译实验的可见历史注入**。本轮主线离线检查也确认 441 定向包没有 442/1037 章资料。

另外，`C0114.J013` 用「フレッシュ」描述黄油口味。这是本作普通用词的另一语境，不应建立「フレッシュ一律等于肉身」的跨作品或全书替换规则。应检索复合名称与适用实体类型。

## 外部领域证据及确定性边界

D&D 官方 D&D Beyond 的 **Flesh Golem** 条目将该怪物描述为由人形生物身体部件缝合、固定而成的构装体。名称中的 flesh 与制作材料形成直接对应，因此这是一个现成的领域名称候选，与本作描述贴合。

本轮以 HTTP 成功读取该官方条目（200），地址为：

```text
https://www.dndbeyond.com/monsters/16863-flesh-golem
```

抓取记录：`artifacts/translation/tenken-cache-clean/verification/p8-flesh-semantics-20261018/web-0.json`。本报告只使用官方正文，不使用其用户评论，也不把该条目其他游戏机制移植成本作设定。

本作原站在线读取超时，作品证据采用已经爬取的原站 HTML 和校验过的语料。检查相应缓存 HTML 的 ruby 节点未发现上述名称的英文拼写注释。这不等于穷尽检查了本作所有出版物、官方译本或作者说明。Cambridge 词典请求为 403，没有据此引用词典内容。

严格区分两类结论：

1. **翻译决策**：flesh 同时解释材料定义、肉兵称呼与现成领域名称；fresh 则还需要假设作品在此特别强调新鲜或未腐。这一性质在所列定义中没有得到说明。按现有证据，flesh 明显更有根据。
2. **作者拼写的直接确认**：仍需本作作者给出的拉丁拼写、明确释义或可靠官方术语记录。目前没有取得这种证据。不能用“逻辑上仍能编出 fresh 的故事”要求放弃更有根据的译法，也不能把概率判断包装成形式逻辑证明。

## 对模型错误的归因

之前的短上下文 D 诊断已经提供尸体材料，模型仍建议“新鲜／未腐”。因此不能将问题完全归因于长上下文注意力；也不能用一次诊断断言模型永远无法消歧。

现有记录更符合三处薄弱环节：没有生成或检索 Flesh Golem 这个整体词义候选；未将同章远处的「肉兵」与片假名名称联系；提出 fresh 后补入原文未说明的“未腐”来维护它。局部窗口改善证据显著性，不能自行补足模型的领域词汇知识和指称推理。

后续若补词典工具，适合返回领域、候选义项、材料定义、出处和不确定状态，由模型结合正文比较；不应加入针对本作的强制字符串替换。本轮没有增加新的付费模型实验，不能声称新主线已经纠正此处译文。
