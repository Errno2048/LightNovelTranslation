## 3. 原文优先的效果复核

### 446：三处名称与单体指代均改善

自动词条匹配选中了`ホーリー・オーダー`，兼容原文中点变体，覆盖`C0446.J007`和`C0446.J008`，共三次出现。历史资料包括：

- `C0180.J069 / C0180.Z073`：圣灵剑清单及“神圣秩序（Holy Order）”这一既有中文用法。
- `C0361.J066`：为对抗狂信剑而制造的圣灵剑设定。

旧续测稿把该名称写成“圣灵骑士团”，一轮修订后仍有残留，并使用“那帮家伙”。本轮初译直接得到：

> 「一百年前还是五百年前，一千年前？已经搞不清了，不过差点被神圣秩序那混蛋破坏的事，我隐约还记得啊！」
>
> 神圣秩序？我记得！是阿莉丝缇亚告诉我的神剑之一！圣灵剑神圣秩序。据说是为了对抗狂信剑法纳提克斯而造的神剑。

三次名称一致，群体指代未复现，无需修订。该章的岩浆／大地魔术也保留了原文方向；不能因参考中文的魔术名不同直接判本稿错误。

### 447：遮字专名依然可能被臆译

`C0447.J032`：

```text
やはり素人だな。殺すとか言っている間に、行動に移すべきなのだ。
プロシュ〇トの兄貴も似たような事を言っていた！
```

本轮译文为“果然是外行。说杀的时候，就该付诸行动。**职业摔〇的兄贵**也说过类似的话！”。“职业摔〇”缺少原文支持，遮字片假名没有被可靠保留或转写。所选12个定向词条不含该表达，模型审校亦未发现。封存后参考中的“普罗修特大哥”仅用于辅助定位，本次没有为该梗继续联网查证或注入答案。

审校对“黒雷転動→黑雷转动”提出minor，猜测历史可能用过“黑雷转生”。引用的`C0449.J061`实际是当前章日文，不能证明历史中文用法。工程标记`historical_usage_needs_external_paragraph`，裁决正确保留为unresolved，没有按猜测改译。
