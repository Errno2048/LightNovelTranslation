# 蜘蛛 Web／文库独立索引试点结果

日期：2026-10-18。模型：`deepseek-flash`。这是一次手动限定候选范围的工程与翻译试点，不是全书匹配准确率，也不是生产译文验收。所有生成稿仍标记为 `working`。

后续连续接入、增量索引、压缩和恢复的首轮实测见 [D6 连续试点结果](translation-cross-edition-sequence-results.md)；本文保留此前单章试点的范围和结论。

## 范围和运行方式

本次实现了独立版本读取、双侧 L1/L2 规划、L2 摘要与事件/实体提取、L2 多对多关联、L1 候选范围的实体对应、用途受限的参考包、翻译、审校和裁决。旧的一一配对流程仍保留。翻译输入以 Web 为事实来源；跨版本正文只作为参考材料，不作为平行译文。

全书目录规划有 Web 6 个 L1／61 个 L2、中文 16 个 L1／70 个 L2。本次实建14个 L2，其中13个属于当前三个实验窗口；另一个是重新选择迷宫负例后保留的缓存节点。规划容量是保守试验配置（131072 上下文、16384 最大输出），不是对上游模型真实上限的声明。窗口为：

| 用例 | Web 来源块 | 文库候选块 | 翻译目标 |
| --- | --- | --- | --- |
| 开篇 | Web 0–9、10–19 | 中文第1卷附近的两个 L2 | `web-main:OPS/page10.html`，S1「日常が終わった日」 |
| 重排迷宫 | Web 200–209、210–219、220–229 | 中文第4卷两个候选和第11卷特意加入的负例 | `web-main:OPS/page214.html`，S25「エルロー大迷宮攻略②」 |
| 结尾分歧 | Web 末条目599 | 中文第16卷两个候选 | `web-main:OPS/page599.html` |

候选范围按章节区域和已发现的误报选择，**没有运行全书候选召回**。关联结果不能据此计算全书 precision/recall。

## L2 关联结果

| 窗口 | 组合数 | event_overlap | related_context | unrelated | uncertain |
| --- | ---: | ---: | ---: | ---: | ---: |
| 开篇 | 4 | 2 | 1 | 1 | 0 |
| 重排迷宫 | 9 | 3 | 0 | 3 | 3 |
| 结尾分歧 | 2 | 0 | 0 | 0 | 2 |
| 合计 | 15 | 5 | 1 | 4 | 5 |

这是模型对候选组合的标注，不等于人工确认的真值。积极信号是：额外加入的同为大迷宫、但叙事时期和人物不同的中文负例，在三个迷宫 Web 块上都被判为 `unrelated`。模型也识别出 Web 路线讨论与文库路线讨论、恶梦残滓的念话事件之间的局部重叠。

主要失误是将一块 Web 的相邻区块中发生的地龙战归到路线讨论区块。冲突解释由解析器保留为 `uncertain`，没有据此注入为对应正文。结尾两组都为 `uncertain`，所以没有用结尾文库内容翻译 Web 结尾。章节标题与阅读序号可辅助定位，但在本例中不能代替事件内容核验。

## 实体匹配和摘要覆盖

两个翻译窗口的实体匹配结果为：开篇22条 `supported`、9条 `ambiguous`、3条 `rejected`；迷宫12条 `supported`、10条 `ambiguous`、3条 `rejected`。`supported` 只是有两侧实际用例的模型候选，不是人工规范或实体穷尽证明。至少一条开篇称谓候选把日文爱称 `岡ちゃん` 连到中文全名，而未保留两者语用形式的差别；这提示映射表需要区分爱称、全名和具体出现用法，不能仅把实体 ID 对上就自动统一措辞。

14个 L2 摘要包含事件、时序和知情状态字段；但 Web 200–209 与220–229两个节点没有输出任何实体，虽然事件摘要仍可用。另有多条模型实体缺少可验证的引用。此类信息不会因为解析成功而升级为可靠术语。当前试点没有真实调用 L1 rollup，也没有测试跨完整 L1 范围的实体穷尽性。

全量摘要表、引用缺失数、空实体节点及调用原文见 [离线报告 JSON](../artifacts/translation/spider-independent-index/pilot-v3/offline-report.json) 和 [逐区块报告](../artifacts/translation/spider-independent-index/pilot-v3/cases/report.md)。增强解析器对13个有完整首轮响应的摘要请求做了离线回放，13个均可解析；另一个首轮请求被截断后重试成功。格式可解析只证明结构恢复，不证明摘要和实体语义正确。

## 翻译对照

两处目标各有 `source_only` 和 `reference_assisted` 首稿，使用同一目标章节和既有的三章 Web 历史/导航。跨版本候选仅出现在 reference 分支。

开篇参考包最终保留中文第1卷 S1 全文76段和相邻章节的10段局部证据，并带3个候选术语。总上下文约55.4k prompt tokens。S1 含目标的“日常校园至教室裂缝”事件；预算裁切曾先删除这个关键章节、只留卷首材料，已在试点中修正为优先保留事件证据，并在整章放不下时降为局部证据。首稿在“岡ちゃん／リホ子”的处理上没有沿用历史用法；审校和裁决引用了实际中文用例，提出“冈姊／真贞子”。这说明局部证据能帮助定位命名差异，但不保证生成模型首轮会采纳。

迷宫 reference 包带8条术语候选和中文 S3 迷宫攻略章节的5段局部证据，总上下文约53.9k prompt tokens。与仅原文首稿相比，参考首稿对若干人名采用了接近既有用法的“哈林斯／卡迪雅”；审校还根据一段历史 Web/中文译名用例，识别并裁决了 `ユーゴー` 的中文形式不一致。它仍保留了错译风险，且关联/术语候选尚未人工全面核验，不能宣称跨版参考整体提升了准确率。

两个窗口都有相同的“仅原文”和“参考”完整 prompt、输出及实际 provider 输入/输出 token 记录。报告页链接到原始捕获文件；例如开篇参考分支可查看[完整输入](../artifacts/translation/spider-independent-index/pilot-v3/cases/opening/reference.full-input.md)、[首稿/最终候选](../artifacts/translation/spider-independent-index/pilot-v3/cases/opening/reference.translation.md)、[修复前首稿](../artifacts/translation/spider-independent-index/pilot-v3/cases/opening/reference.draft.translation.md)及[各阶段请求/响应索引](../artifacts/translation/spider-independent-index/pilot-v3/cases/opening/reference.model-trace.md)。迷宫材料对应的文件位于相邻 `reordered/` 目录。

## 审校与修复风险

审校可以将外版的实际译名用例定位到正文，并给出可追溯 finding；裁决在这两个样例中确认了“真贞子／冈姊”和 `ユーゴー` 的具体名称用法。然而，修复后复审没有报告段落结构问题：开篇首稿有89个非空段落，修复稿被合并成一个段落。这个修复稿不能直接用于 EPUB。

因此当前默认行为是不自动修复，修复仅作为显式实验选项。已改为只把 `confirmed` finding 交给修复模型，但这不足以防止输出退化；需要另行把段落结构纳入修复约束/校验，并保证失败时保留首稿。目前两份首稿、审校、裁决和这次修复失败都已留存供检查。

## 调用成本和验证

当前目录有80个完整响应：35个从前序试点原样复用，45个为本分支新增；另有1个失败调用（首轮摘要截断），没有未决远程请求。完整响应共记录约3,535,863 prompt tokens、248,084 completion tokens；其中本分支新增完整响应用量为约2,296,326 prompt tokens、59,152 completion tokens。失败调用不含在 provider 用量合计中。使用了本地 tokenizer 的离线 token 估算和1.05膨胀余量；最终用量取捕获响应的 provider usage。

全量测试：480 passed，1条既有 `pkg_resources` 弃用警告。解析器/试点针对测试：30 passed。`git diff --check` 通过。

## 结论和边界

该实现已能在明确的小候选池中做独立 L2 摘要比较、保留多对多和不确定结果，并为选中的关联生成带明确用途的参考包。在两个短翻译窗口中，局部证据和术语候选提供了可用的查证线索，足以继续小规模评估。

本次没有完成全书 L1 候选召回、跨全 L1 的目录匹配、实体提取完整性保障、L1 rollup、连续增量翻译/压缩、自动复审质量门，也没有证明 reference-assisted 翻译整体优于 source-only。结尾候选弃权和修复导致段落合并是保留的未解决问题。**这是可继续迭代的原型，不是 P9 全量验收或生产翻译管线。**
